# create-tokru-profile

> ⚠️ Early experimental release — proceed with caution.

Push button, get profile.

A CLI that builds your professional portfolio, deploys it as a personal website, and registers it on [tokru.ai](https://tokru.ai) — machine-readable and discoverable by AI agents.

## Usage

```bash
npx create-tokru-profile
```

## What happens

1. Answer a few questions
2. Your portfolio deploys to a live URL you own
3. It's registered on the Tokru registry — searchable by humans and queryable by AI agents
4. You get a `TOKRU.md` to drop into any AI assistant — it manages your profile from there
